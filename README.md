# AI Course Recommendation System (Hybrid Collaborative Filtering)

An intelligent **hybrid course recommendation engine** that combines **Content-Based Filtering** and **Collaborative Filtering** to suggest personalized courses to users based on their profile, skills, search history, and enrollment behavior.

---

## ✨ Features

- Hybrid recommendation (Content + Collaborative)
- TF-IDF + Cosine Similarity for content matching
- Language-aware recommendations
- Creator name enrichment
- Personalized based on user skills, description & search history

---

## 🛠 Tech Stack

- **Framework**: FastAPI
- **Data Processing**: Pandas + Scikit-learn
- **Database**: MySQL (SQLAlchemy)
- **NLP**: TF-IDF Vectorizer + Cosine Similarity
